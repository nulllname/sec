- 检查系统相关信息
- 用户登录爆破/登录记录分析
- 异常端口进程分析（挖矿/隐藏/可疑）
- 网络连接分析（外联/高危端口/挖矿/开放端口详细信息）

- 文件篡改检测（敏感文件修改/临时目录可执行文件）
- 系统日志、应用日志、安全日志异常分析（日志篡改/异常命令、）
- 挖矿行为专项检测（挖矿文件/矿池连接/GPU使用）
- 中间件与框架版本检测 （新增功能）
- 最近文件操作记录
- 隐藏文件检测
- 启动项、计划任务
- 最近网络访问记录
- ssh未授权公钥
- ssh软连接后门检测
